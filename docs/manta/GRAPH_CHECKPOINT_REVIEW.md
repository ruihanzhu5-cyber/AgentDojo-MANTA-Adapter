# Graph checkpoint 实现自查

日期：2026-10-19。结论：当前固定源码和安全轮次边界通过零付费验收；没有启动真实采集或续跑。

全部 41 项测试通过：原有预算 3、原指标 12、第一阶段重放 9、本轮 checkpoint/图机制 17。
日志：本地 `results/v1/graph_checkpoint_qa_all_tests_04.log`，41 tests，OK。

测试期间 HTTP 被禁止。这不是跨模型独立审计，也没有用模拟输出冒充真实实验结果。

## 自查发现与修正

| 风险 | 修正 |
|---|---|
| 默认 transactional_star 重新覆盖图变化 | G0/G1 同时使用官方 commit_once，明确列为新配置 |
| 从头重跑或录制回复重放不等于状态恢复 | 固定原生源码 AST，在下一轮入口保存全部 frame，恢复后直接执行剩余原始循环和 finalize |
| NullDescriptor 仍有 monitor_records | 把监控状态纳入对象图，完整元数据等价性测试通过 |
| 日历和邮件校验器会重建索引 | 官方模型按白名单直接恢复字段、字段集合、私有/额外字段及 enum/datetime，不再次运行校验器 |
| 环境对象和历史工具输出可能共享引用 | 用同一个 JSON 对象图保存；分两步恢复环境并重绑 handler，再复用同一解码 cache 恢复 frame |
| 只有字符串网页工具的验收不够 | 增加新增日历事件、删除/新增邮件索引、附件引用、银行交易及历史工具输出 alias 测试 |
| 空输出导致官方目标被默认当作未达成 | prefix 用 incumbent answer 和实际环境/调用评分；非 boolean 的官方结果拒绝进入对照 |
| 节点、角色或 ContextPolicy 混入图干预 | 用原生 GroupSpec 切换；保持 AgentNode 不变；非图 frame 完整回编码一致性校验 |
| 只改 adjacency 展示，没有改变实际执行 | 记录 executor 图与 execution_signature；首轮配对门槛要求执行确实不同 |
| 本地 RNG 或 client 序号/配置改变 | 保存 Python/NumPy RNG、请求序号和无秘密 client profile，设置不同即拒绝 |
| 达到请求保护上限被误认为完整 | 记录 request_guard_failures，不能进入有效前缀/有效续跑 |
| 工具参数错误被当成基础设施失败 | 保留普通工具域错误并计数，官方任务结果反映执行后果；请求错误/截断/超时另列不完整 |
| 没有足够合格状态时强行凑数 | 固定 12 候选顺序，最多 6 合格状态；实际 N 决定分母，0 则明确停止 |
| 重复启动或覆盖原实验 | 文件锁、活跃 PID 检查、独立目录与台账、冻结源码/任务/快照校验，保护原正式和局部重放目录 |

## 有意保留的边界

- 原生 main 文件没有修改。run 方法的源码 SHA 必须为当前已审查版本，AST 入口结构变化就拒绝。
- 只支持 NullDescriptor、白名单原生状态类型和已加载的官方 suite domain model；未知对象、未知状态或不可保存 cache 不会被静默忽略。
- 安全边界是实际进入下一轮的原生 controller 入口，当前 max_turns=2，所以研究样本都是实际 repair 后的状态。
- 本轮不覆盖先前设想的 mutation/nonmutation 混合样本，也不声称完整覆盖默认 hybrid audit/在线学习。
- 不恢复远程模型内部随机性、HTTP 连接池或线程锁；每次调用是独立 provider 请求，完整消息由保存状态重新生成。
- 图干预包含原生图模式的调度语义，后续 prompt 可以变化；不声称初始 context 不变意味着未来输入逐字不变。
- 单个预定义图干预不能代表所有图防御；无攻击事件不能被当成“图无效”的证据。
- 真实 API 的连通性和运行结果只能在用户终端启动后观察，本次验收未产生付费请求。
